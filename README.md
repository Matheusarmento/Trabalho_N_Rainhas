
# Problema das N-Rainhas

Projeto desenvolvido para a disciplina de Inteligência Artificial do curso de Análise e Desenvolvimento de Sistemas do IFPI - Campus Picos.

## Objetivo

Resolver o problema das N-Rainhas utilizando dois algoritmos de busca informada:

- A* (A-Star)
- Busca Gulosa

## Funcionamento

O programa recebe a quantidade de rainhas e procura posicioná-las em um tabuleiro N x N, sem que duas rainhas se ataquem.

## Heurística

A heurística calcula a quantidade de pares de rainhas que estão em conflito.

## Custo

O custo para gerar um novo estado é igual a 1.

## Tecnologias

- Python 3
- Visual Studio Code

## Como executar

1. Abra o terminal na pasta do projeto.
2. Execute:

python3 n_rainhas.py

3. Informe a quantidade de rainhas.
